Rita's 18th Birthday site

Deploy on Vercel:
1. Go to vercel.com/new, or open your Vercel dashboard and choose Add New > Project.
2. To upload without Git, install the Vercel CLI (npm i -g vercel), open a terminal in this folder and run: vercel --prod
   Or drag this whole folder onto the Vercel dashboard.
3. Framework preset: "Other". No build command and no output directory needed.

Files:
  index.html          the page
  assets/profile.jpg  profile picture in the navigation bar
  assets/pic1.jpg     gallery photo
  assets/pic3.jpg     hero and gallery photo
